# Customer Segmentation Project

## Project Overview
This project performs Customer Segmentation using Machine Learning techniques.  
The main goal is to divide customers into different groups based on their annual income and spending behavior.

KMeans Clustering algorithm is used to identify customer groups.

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab
- Excel / CSV Dataset

---

## Dataset Information

The dataset contains customer details such as:

| Column Name | Description |
|---|---|
| CustomerID | Unique customer ID |
| Gender | Male/Female |
| Age | Customer age |
| Annual Income | Customer yearly income |
| Spending Score | Customer spending behavior |

---

## Machine Learning Algorithm

### KMeans Clustering

KMeans algorithm is used to:
- group similar customers
- analyze customer behavior
- identify customer segments
